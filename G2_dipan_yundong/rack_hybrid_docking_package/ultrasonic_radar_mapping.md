# G2 超声波雷达方向映射

2026-06-09 现场实机贴标确认，本项目按下面方向使用 8 个底盘超声波雷达：

| ID | 方向 | 用途 |
| --- | --- | --- |
| 0 | 前方 | 前进靠近、155mm 抓取精定位、500mm 放料精定位 |
| 1 | 前方 | 前进靠近、155mm 抓取精定位、500mm 放料精定位 |
| 2 | 右侧 | 只做侧向状态记录，不并入前方或后方保护 |
| 3 | 右侧 | 只做侧向状态记录，不并入前方或后方保护 |
| 4 | 后方 | 后退障碍保护 |
| 5 | 后方 | 后退障碍保护 |
| 6 | 左侧 | 只做侧向状态记录，不并入前方或后方保护 |
| 7 | 左侧 | 只做侧向状态记录，不并入前方或后方保护 |

代码默认分组：

```python
front_ultrasonic_ids = (0, 1)
right_ultrasonic_ids = (2, 3)
rear_ultrasonic_ids = (4, 5)
left_ultrasonic_ids = (6, 7)
```

关键约束：

- 前进/精定位只能使用 `0/1`，不能把 `2/3` 右侧探头混进去。
- 后退保护只能使用 `4/5`，不能把 `6/7` 左侧探头混进去。
- 转向诊断可以同时记录四个方向，但不能把侧向读数当作前后距离。
- 旧分组 `0,1,2,3` 为前方、`4,5,6,7` 为后方是错误的，会造成侧向障碍误判。
